# 🎵 TuneHub Application

## 📌 Description
TuneHub is a web-based music application developed using Java Full Stack technologies. It allows users to explore songs, register/login, and interact with music content through a simple and user-friendly interface.

---

## 🚀 Features
- User Registration & Login Authentication  
- Browse and explore songs  
- Play music (if implemented)  
- Admin can manage songs (add/update/delete)  
- Responsive user interface  

---

## 🛠️ Technologies Used
- **Backend:** Java, Servlets, JSP  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** Oracle (JDBC)  
- **Server:** Apache Tomcat
